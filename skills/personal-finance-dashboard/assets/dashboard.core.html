Return assumptions and sources

Indian and US equity both use 12% a year in rupees. That is a conservative long-run figure; 14% is treated as upside, not the plan. US returns in rupees include some rupee weakening, but US valuations are high today, so the model does not assume more than India. GoldBEES uses 8% (gold’s long-run return is closer to inflation plus 1–2% than its recent 10-year run). EPF uses the declared 8.25% and PPF 7.1%; both can change. NPS uses 10%. After 60 the corpus is assumed to earn 8% in a balanced mix.
